# Démo

## Installation

```bash
pip install -r requirements.txt
```

## Lancer la démo

```bash
python demo.py v2/model_v2.h5
```

La webcam s'ouvre et demande de montrer chaque objet à tour de rôle. Il faut maintenir l'objet devant la caméra pendant 3 secondes pour valider la manche. Appuyer sur `q` ou `Échap` pour quitter.

## Objets à montrer

| Classe    | Objet                |
|-----------|----------------------|
| objet1    | Fourchette            |
| objet2    | Stylo 4 couleurs      |
| objet3    | Fluo orange           |
